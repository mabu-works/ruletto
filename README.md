# ルレット｜汎用ルーレットメーカー

項目を入力するだけで、カラフルなホイールのルーレットが作れる静的Webサイトです。ビルド不要で、ブラウザだけで動作します。

## 機能

- 項目リストの編集（行の追加・削除、最大50件、各項目の色ドット表示）
- 1行1項目のテキストエリアによるまとめて編集（リストへ反映）
- Canvas で描くカラフルなホイール（項目数に応じて自動で色分け・ラベル配置）
- 「回す」でイージング（easeOut）付き回転アニメーション、止まった項目を大きく表示
- 履歴リスト（最新20件、時刻つき）
- プリセット3種をワンタップでセット：晩ごはん／罰ゲーム／係決め
- 設定を URL ハッシュにエンコードした共有リンクのコピー／開いたときの自動復元
- 項目リストと主要な設定（最後の結果・履歴）の自動保存（localStorage）／再訪時の自動復元、「保存データを消去して初期化」ボタンで消去可能
- 「結果を印刷」ボタンで、項目一覧と当選結果だけを印刷
- 結果をテキスト（「ルーレットの結果：◯◯」）でコピー
- PWA 対応（ホーム画面に追加可能、オフラインキャッシュ）
- ダーク／ライトテーマ切り替え対応（既定はダーク、選択はブラウザに保存）

## 使い方

1. 項目を入力します（リスト編集・テキストエリア・プリセットのどれでもOK）。
2. 「回す」（またはホイールをタップ）でルーレットが回ります。
3. 止まった項目が大きく表示され、履歴に残ります。「結果をコピー」でテキスト共有できます。
4. 「共有リンクをコピー」で現在の項目セットを URL として共有できます。
5. 項目リストは自動でブラウザに保存されるため、閉じて開き直しても続きから使えます。消したいときは「保存データを消去して初期化」を押してください。
6. 「結果を印刷」で、項目一覧と当選結果だけを紙に印刷できます（クラス名簿の抽選結果の掲示など向け）。

## 技術メモ

- 素の HTML / CSS / JavaScript のみ。外部リソース・ライブラリ不使用、フォントはシステムの日本語フォントスタック。
- 当選判定は、回転角を 2π で正規化し、真上のポインタ位置に来たセグメントを算出しています。
- 回転は requestAnimationFrame ＋ easeOutQuart で約4.2秒かけて減速します。
- 共有リンクは設定 JSON を UTF-8 → Base64URL 化して URL ハッシュに入れています。サーバーには何も送信されません。
- Service Worker（sw.js）が同一オリジンの GET をキャッシュします（キャッシュ名: ruletto-v3）。

## 仕様メモ（2026-11-20 テストで確認）

- 当選判定の一貫性：ポインタ位置のセグメントと表示される当選項目は、項目数2〜50×24,000件超の照合で完全一致（境界ちょうどの同点を除く。下記の既知事象を参照）。確率分布も実スピン計34,000回で均等を確認した。
- 境界ちょうどの同点について：ポインタがセグメント境目に浮動小数点の限界精度（1e-15 rad 以下）で重なった場合のみ判定が丸めで揺れ得る。最終回転角は乱数由来のため、実使用での発生確率は実質ゼロであり、対処は不要と判断している。
- 重複名は許容される（同じ名前の項目が複数あると、その名前の見た目上の当選確率が上がる）。
- 空欄の項目名も許容される。空欄項目が当選すると結果表示は名前なし（「🎉 」）になり、履歴にも空ラベルで記録される。
- 項目リストの永続保存は共有リンク（URLハッシュ）のみ。履歴はメモリ上のみで、再読み込みで消える。（※この記述は 2026-11-20 改修前の仕様。下記の改修メモが現行仕様）

## 仕様メモ（2026-11-20 改修：クラス40〜50人での実用向け）

- 項目上限を 24件 → 50件に引き上げた（MAX_ITEMS=50）。追加ボタンの無効化、一括反映の slice、共有リンク復元時の検証（1〜50件のみ受理、51件は拒否）のすべてが MAX_ITEMS を参照する。色は従来どおり12色パレットの循環で変更していない。
- ホイールラベルは区画数に応じて段階的に縮小する：フォントサイズは 〜8件=24px／〜16件=20px／〜24件=17px／〜36件=14px／37件〜=12px（基準半径306px換算）、省略する文字数は 〜8件=10文字／〜16件=9文字／〜24件=8文字／〜36件=7文字／37件〜=6文字（labelFontSize / labelMaxChars / truncateLabel）。50件ではホイール上の判読に限界がある前提で、ホイール脇の項目リスト表示は従来どおり維持し、当選結果は従来どおり大きく表示する（この2点は意図的に変更していない）。
- 印刷：「結果を印刷」ボタンを追加。style.css の @media print で入力UI・ホイール・履歴・ヘッダー等を隠し、印刷専用エリア（#printArea、画面では非表示）の項目一覧と当選結果だけが紙面に出る。当選していない場合は「当選結果：まだ回していません」と出す。
- 自動保存：項目リストと主要な設定（最後の結果・履歴）を localStorage キー `ruletto-data` に、入力が変わるたびに保存する（直接編集・追加・削除・一括反映・プリセット・スピン確定時）。テーマキー `ruletto-theme` とは別キー。復元の優先順位は 共有リンク（URLハッシュ）＞ 自動保存データ。壊れた保存データや51件以上の保存データは無視して初期項目で開く。
- 消去手段：既存にリセット導線がなかったため「保存データを消去して初期化」ボタンを追加した。保存データを削除し、項目を初期値（A〜D）に戻し、結果と履歴も消す。消去直後は自動保存しないので、再訪時は初期項目で開く。
- テスト（~/workspace/tmp/ruletto-test/test-ruletto.mjs）：改修前は 33 passed / 1 failed（不合格は境界ちょうどの同点を数える従来テストで、README既知事象どおり浮動小数点の同点が原因）。改修で当該テストは同点を別扱いにして検証範囲を 2〜50件へ拡張し、上限50・一括反映の上限・ラベル計算・保存→復元・印刷の新規テストを追加して 56 passed / 0 failed。
- Service Worker のキャッシュ名を ruletto-v2 → ruletto-v3 に上げた（app.js / style.css / index.html の変更を確実に行き渡らせるため）。
