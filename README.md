# ルレット｜汎用ルーレットメーカー

項目を入力するだけで、カラフルなホイールのルーレットが作れる静的Webサイトです。ビルド不要で、ブラウザだけで動作します。

## 機能

- 項目リストの編集（行の追加・削除、最大24件、各項目の色ドット表示）
- 1行1項目のテキストエリアによるまとめて編集（リストへ反映）
- Canvas で描くカラフルなホイール（項目数に応じて自動で色分け・ラベル配置）
- 「回す」でイージング（easeOut）付き回転アニメーション、止まった項目を大きく表示
- 履歴リスト（最新20件、時刻つき）
- プリセット3種をワンタップでセット：晩ごはん／罰ゲーム／係決め
- 設定を URL ハッシュにエンコードした共有リンクのコピー／開いたときの自動復元
- 結果をテキスト（「ルーレットの結果：◯◯」）でコピー
- PWA 対応（ホーム画面に追加可能、オフラインキャッシュ）
- ダーク／ライトテーマ切り替え対応（既定はダーク、選択はブラウザに保存）

## 使い方

1. 項目を入力します（リスト編集・テキストエリア・プリセットのどれでもOK）。
2. 「回す」（またはホイールをタップ）でルーレットが回ります。
3. 止まった項目が大きく表示され、履歴に残ります。「結果をコピー」でテキスト共有できます。
4. 「共有リンクをコピー」で現在の項目セットを URL として共有できます。

## 技術メモ

- 素の HTML / CSS / JavaScript のみ。外部リソース・ライブラリ不使用、フォントはシステムの日本語フォントスタック。
- 当選判定は、回転角を 2π で正規化し、真上のポインタ位置に来たセグメントを算出しています。
- 回転は requestAnimationFrame ＋ easeOutQuart で約4.2秒かけて減速します。
- 共有リンクは設定 JSON を UTF-8 → Base64URL 化して URL ハッシュに入れています。サーバーには何も送信されません。
- Service Worker（sw.js）が同一オリジンの GET をキャッシュします（キャッシュ名: ruletto-v2）。

## 仕様メモ（2026-11-20 テストで確認）

- 当選判定の一貫性：ポインタ位置のセグメントと表示される当選項目は、項目数2〜24×21,000件超の照合で完全一致。確率分布も実スピン計34,000回で均等を確認した。
- 境界ちょうどの同点について：ポインタがセグメント境目に浮動小数点の限界精度（1e-15 rad 以下）で重なった場合のみ判定が丸めで揺れ得る。最終回転角は乱数由来のため、実使用での発生確率は実質ゼロであり、対処は不要と判断している。
- 重複名は許容される（同じ名前の項目が複数あると、その名前の見た目上の当選確率が上がる）。
- 空欄の項目名も許容される。空欄項目が当選すると結果表示は名前なし（「🎉 」）になり、履歴にも空ラベルで記録される。
- 項目リストの永続保存は共有リンク（URLハッシュ）のみ。履歴はメモリ上のみで、再読み込みで消える。
