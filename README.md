# ルレット｜汎用ルーレットメーカー

項目を入力するだけで、カラフルなホイールのルーレットが作れる静的Webサイトです。ビルド不要で、ブラウザだけで動作します。

| 項目 | 内容 |
|---|---|
| バージョン | 1.0.0 |
| 状態 | 公開中 |
| 稼働先 | [ruletto.vercel.app](https://ruletto.vercel.app)（Vercel） |
| 実装 | 静的 Web サイト（素の HTML / CSS / JavaScript）＋ Windows 版（.NET 8 / WinForms） |
| 更新履歴 | [CHANGELOG.md](CHANGELOG.md) |

## ✨ 機能

- 項目リストの編集（行の追加・削除、最大50件、各項目の色ドット表示）
- 1行1項目のテキストエリアによるまとめて編集（リストへ反映）
- Canvas で描くカラフルなホイール（項目数に応じて自動で色分け・ラベル配置）
- 「回す」でイージング（easeOutQuart）付き回転アニメーション、止まった項目を大きく表示
- 履歴リスト（最新20件、時刻つき）
- プリセット3種をワンタップでセット：晩ごはん／罰ゲーム／係決め
- 設定を URL ハッシュにエンコードした共有リンクのコピー／開いたときの自動復元
- 項目リストと主要な設定（最後の結果・履歴）の自動保存（localStorage）／再訪時の自動復元、「保存データを消去して初期化」ボタンで消去可能
- 「結果を印刷」ボタンで、項目一覧と当選結果だけを印刷
- 結果をテキスト（「ルーレットの結果：◯◯」）でコピー
- PWA 対応（ホーム画面に追加可能、オフラインキャッシュ）
- ダーク／ライトテーマ切り替え対応（既定はダーク、選択はブラウザに保存）

## 📝 使い方

1. 項目を入力します（リスト編集・テキストエリア・プリセットのどれでもOK）。
2. 「回す」（またはホイールをタップ）でルーレットが回ります。
3. 止まった項目が大きく表示され、履歴に残ります。「結果をコピー」でテキスト共有できます。
4. 「共有リンクをコピー」で現在の項目セットを URL として共有できます。
5. 項目リストは自動でブラウザに保存されるため、閉じて開き直しても続きから使えます。消したいときは「保存データを消去して初期化」を押してください。
6. 「結果を印刷」で、項目一覧と当選結果だけを紙に印刷できます（クラス名簿の抽選結果の掲示など向け）。

## 🪟 Windows 版

`windows/` フォルダに、同じ仕様の Windows アプリ（.NET 8 / WinForms）があります。Web 版と同じカラーパレット・ラベル縮小ルール・回転アニメーション（4200ms、easeOutQuart）で、オフラインで使えます。

- ビルド: `windows/build.bat`（Windows）または `windows/build.sh`（Linux）で `windows/dist/Ruletto.exe` を生成
- 項目は1行1項目のテキスト編集（最大50件）。プリセット・履歴（最大20件）・結果コピーに対応
- exe は GitHub Release には添付しません（リリースはノートのみの方針）。各自ビルドしてください。

## 📋 技術メモ

- 素の HTML / CSS / JavaScript のみ。外部リソース・ライブラリ不使用、フォントはシステムの日本語フォントスタック。
- 純粋な計算（当選判定・ラベル寸法・共有リンク符号化・保存データ変換）は `js/wheel-core.js` に分離し、`tests/` の単体テストで固定している。
- 当選判定は、回転角を 2π で正規化し、真上のポインタ位置に来たセグメントを算出しています。
- 回転は requestAnimationFrame ＋ easeOutQuart で約4.2秒かけて減速します。
- 共有リンクは設定 JSON を UTF-8 → Base64URL 化して URL ハッシュに入れています。サーバーには何も送信されません。
- Service Worker（sw.js）が同一オリジンの GET をキャッシュします（キャッシュ名: ruletto-v1）。
- 設計判断と仕様の詳細は [DESIGN.md](DESIGN.md) を参照。
